CodoRustDesk Flutter - Windows x64 Release

Extract the complete ZIP folder and double-click rustdesk.exe.
Keep all DLLs and the data folder beside the executable.
The separate portable EXE extracts its payload into LocalAppData/rustdesk.
Neither package needs Rust, Flutter, Python or Visual Studio on the target PC.

For the RustDesk public server, open Settings > Account > Login and use Google,
GitHub or another offered provider. Complete authorization in your own browser.
Username/password login is not offered by the public server.
https://github.com/rustdesk/rustdesk/wiki/Login-required-for-public-server

These are unsigned local builds, not official signed RustDesk installers.
They retain RustDesk's application/configuration/service naming. Choosing Install
inside the app may update an existing RustDesk installation.
Optional hwcodec/vram hardware acceleration is not enabled by these scripts.
Windows service and virtual display/printer drivers are not installed merely by
starting the portable app; additional driver packages are not bundled here.
